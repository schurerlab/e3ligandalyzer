Ligand pages

Each LR code is a structure-aware recruiter record.

A recruiter page is not just a SMILES lookup. It resolves the recruiter code to metadata, descriptor values, PDB context, ligand identity, SASA summary, atom-level solvent exposure, and downloadable structural files.

2D recruiter structure 3D PDB viewer SASA atom exposure PDB/SDF downloads SMILES mapping
How should I interpret SASA color coding?
Green marks moderately exposed atoms, yellow marks stronger exposure, and red marks highly exposed atoms. Atoms below the exposure threshold or without SASA are rendered normally. Use this as a practical linker-vector screen, not as a replacement for full energetic modeling.

Metric glossary

Know what the numbers mean.

QED, MW, LogP, and Lipinski
These descriptor values summarize drug-likeness and physicochemical behavior. They are useful for triage, but final degrader design also depends on linker chemistry, ternary complex geometry, permeability, and biological context.
Scaffold diversity and Shannon Index
The Shannon-style diversity score captures how broadly recruiter records are distributed across scaffold families. Higher values generally suggest broader chemotype diversity.
Ligase–scaffold connectivity
Connectivity reflects how often scaffolds appear across ligase contexts. A highly connected scaffold may indicate reusable recruiter logic or promiscuous chemotype behavior.
% Exposed and % Buried
These SASA-derived fields summarize how much of a recruiter is solvent-accessible versus buried in the binding context. Exposed atoms can suggest linker attachment opportunities.

FAQ

Common questions.

Why do some recruiters have missing data?
Some recruiter codes may have descriptor or SMILES data but lack complete structure, SASA, or file-level context. Missing pages are routed to a support page so they can be curated or reported.
Why can one ligand appear more than once?
The same chemical ligand can appear in different ligases, PDB entries, variants, poses, or structural contexts. LR records preserve this structure-level context instead of collapsing everything into one chemical-only entry.
Where is the API documentation?
The complete API documentation now lives on the API Reference page. This Docs page is focused on how to use the Ligandalyzer as a researcher.
How can collaborators contribute?
Use the Submit Data / Contribute page or contact the team directly at jxs794@miami.edu with structures, ligase systems, recruiter data, scaffold notes, or feature ideas.
