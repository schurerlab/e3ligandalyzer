Changelog

June 2026 — scholarly resource upgrade

The site now includes dedicated Methods, Database Schema, Release Notes, Submit Data / Contribute, and Case Studies pages to support citation, transparency, and researcher onboarding.

Current database snapshot

Live statistics on this page are computed from the current SQLite-backed application snapshot rather than entered manually. This keeps the release page aligned with the deployed data state.

Formal release archiving

Archived release packaging, frozen version tags, and machine-readable release manifests remain planned follow-up work for publication-grade release tracking.

Known limitations

  • The current public site does not yet expose a formal semantic release label or archived release tarball index.
  • Scaffold totals in the live app snapshot may differ from manuscript-facing or external pipeline summaries when upstream curation has moved faster than formal release packaging.
  • Missing-data counts shown here reflect the currently loaded SASA summary snapshot and should not be interpreted as a global guarantee for every future table or asset type.
  • Users should treat the release manifest, schema page, and methods page as a set when documenting reproducible downloads.

Archived prior releases

No formal archived prior releases are exposed on the public site yet. Once archived releases are published, this section should list the release label, release date, snapshot counts, manifest link, and any schema or pipeline changes that affect reproducibility.

Citation and reproducibility note

If you use the current workflow, code, or generated dataset, cite the associated E3 Recruiter Ligandalyzer manuscript when available. The pipeline repository currently suggests the following interim citation language:

Schulz JM, Reynolds RC, Schürer SC. E3 Recruiter Ligandalyzer: A Structure-First, Ligand-Centric Platform for E3 Ligase Recruiter Selection. Manuscript in preparation.

Maintenance policy

The codebase and update repositories indicate an actively maintained, appendable resource. New structural additions should move through the curated update workflow, carry manifest and audit information, and regenerate downstream tables before being treated as release-ready.
