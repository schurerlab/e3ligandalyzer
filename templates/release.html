Changelog

Version 1.0 — Initial public database release

The public V1 release establishes the curated structure-first database snapshot and researcher-facing site experience for E3 ligase recruiter exploration, scaffold comparison, SASA interpretation, and release-aware downloads.

Publication-facing resource layer

Version 1 includes dedicated Methods, Database Schema, Release Notes, Submit Data / Contribute, and Case Studies pages for publication-grade transparency and researcher onboarding.

Release-aware downloads

Version 1 also includes a human-readable download manifest alongside the preserved machine-readable raw JSON manifest used by scripts and automation workflows.

Version 1 notes and limitations

  • Version 1 is a curated structure-first snapshot, not a claim of exhaustive coverage of every E3 ligase or recruiter reported in the literature.
  • Future yearly releases may expand ligase coverage, recruiter mappings, scaffold annotations, and SASA-linked assets as new structures and curation passes become available.
  • Scaffold summaries may evolve in future releases as curation improves and additional clustering or unification passes are incorporated.
  • Users should pair downloaded files with the V1 manifest, schema page, and methods page when documenting reproducible analyses.

Archived prior releases

Version 1 is the first public database release, so no earlier public releases are archived. Future yearly releases should be listed here with version label, release identity, summary counts, manifest link, and any schema or methods changes that affect reproducibility.

Citation and reproducibility note

If you use the current workflow, code, or generated dataset, cite the associated E3 Recruiter Ligandalyzer manuscript when available. The pipeline repository currently suggests the following interim citation language:

Schulz JM, Reynolds RC, Schürer SC. E3 Recruiter Ligandalyzer: A Structure-First, Ligand-Centric Platform for E3 Ligase Recruiter Selection. Manuscript in preparation.

Maintenance policy

The database is intended to be reviewed and updated yearly. New E3 ligases, recruiter structures, scaffold annotations, and SASA-linked assets can be incorporated in future yearly releases after they pass curation and validation.

Community-submitted additions and corrections are reviewed through the Submit Data / Contribute workflow before release inclusion.
