Base URL

For now, use STAN as the live API host. When the production domain is ready, replace the base URL with https://e3ligandalyzer.com/api. 

export BASE="https://stan.rove-vernier.ts.net/api"

Tip: after copying this once, every terminal block that starts with $BASE will work in the same shell session.

Canonical recruiter code format

Use LR followed by five digits.

LR00001

Copy-paste terminal quickstart

These commands are meant to paste directly into macOS/Linux Bash or Zsh. They use curl, python -m json.tool, and unzip.

JSON sanity check

View the full download manifest

Confirms the API is reachable and prints pretty JSON.

curl -sS "https://stan.rove-vernier.ts.net/api/download/manifest" | python -m json.tool
Ligase bundle

Download all CRBN PDB + SDF files

This is the exact style of command that worked in your terminal.

curl -L "https://stan.rove-vernier.ts.net/api/download/ligase/CRBN/all.zip" -o CRBN_ligandalyzer_bundle.zip
unzip -q CRBN_ligandalyzer_bundle.zip -d E3Ligandalyzer_CRBN

Python workflows

These are real Python snippets. Paste them into a Python session or save them as .py files.

Python ZIP download

Download and extract one ligase bundle

import requests, zipfile, io

BASE = "https://stan.rove-vernier.ts.net/api"
url = f"{BASE}/download/ligase/CRBN/all.zip"

r = requests.get(url, timeout=120)
r.raise_for_status()

with zipfile.ZipFile(io.BytesIO(r.content)) as z:
    z.extractall("E3Ligandalyzer_CRBN")

print("Downloaded CRBN PDB/SDF bundle")
Python recruiter bundle

Download selected LR recruiter bundles

import requests

BASE = "https://stan.rove-vernier.ts.net/api"
codes = "LR00001,LR00002,LR00003"

url = f"{BASE}/download/recruiters.zip?codes={codes}"
r = requests.get(url, timeout=120)
r.raise_for_status()

with open("selected_recruiters.zip", "wb") as f:
    f.write(r.content)

print("Saved selected_recruiters.zip")
Python JSON query

Load CRBN recruiters into pandas

import requests
import pandas as pd

BASE = "https://stan.rove-vernier.ts.net/api"
url = f"{BASE}/featured-recruiters?ligase=CRBN&min_qed=0.5&limit=500"

rows = requests.get(url, timeout=60).json()
df = pd.DataFrame(rows)

print(df.head())
print(df.shape)

Browser JavaScript examples
