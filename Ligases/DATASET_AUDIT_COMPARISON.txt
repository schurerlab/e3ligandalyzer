LESSONS LEARNED

ROOT CAUSE OF OLD DATASET FAILURE:
The original dataset used a flawed "ligase name → assume PDB IDs" approach
without biological verification, resulting in:
• Bacterial enzymes labeled as human E3 ligases
• Unrelated human proteins (GPCRs, phosphatases) labeled as E3 ligases
• Wrong organism assignments (bacterial vs. human)
• Wrong protein family assignments

SUCCESS FACTORS FOR NEW DATASET:
The new dataset used a "PDB → protein → E3 validation" approach with:
• Curated E3 ligase list from literature
• Direct PDB file parsing to extract protein identity
• Strict ligand validation (HETATM confirmation)
• Cross-referencing with existing dataset
• 6-step validation protocol

KEY INSIGHT:
NEVER assume PDB → ligase mapping.
ALWAYS derive ligase identity FROM PDB metadata.
When uncertain → discard (prioritize correctness over dataset size).
