# How to cite E3 Ligandalyzer

Please cite the published Zenodo software release:

> Schulz, J. M., Bardhan, M., Reynolds, R. C., LeRoy, G., Reinberg, D., & Schürer, S. C. (2026). *E3 Ligandalyzer* [Computer software]. Zenodo. https://doi.org/10.5281/zenodo.23374710

The hosted [citation page](https://e3ligandalyzer.com/citation) provides this citation and an RIS download.

For a formal software citation, use the metadata in `CITATION.cff`.
